# Israel Statecraft Simulation — Codex Handoff Package

This archive contains the full product handoff developed through the design discussion: product vision, authored worldview, Atlas seed, research requirements, implementation HLD, test matrix, and visual references.

The package intentionally separates:

- **engine and product requirements** from
- **the authored geopolitical worldview** from
- **the initial historical/counterfactual Atlas seed**.

That separation allows the same engine to support future scenarios without rewriting the product architecture.
