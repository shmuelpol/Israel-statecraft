# Israel-statecraft
Runtime-AI driven state decision making simulation


<img width="1907" height="896" alt="image" src="https://github.com/user-attachments/assets/f6f3adef-4668-4c5f-ab52-0d93d3299256" />


This is an AI platform based software - you need an AI agent (e.g. Claude code) running on your machine to use its full version (deterministic mock version is runnable).

This is a POC - it is designed to make people understand tough strategic decisions, trade offs, and the realism of war. It also, like all uncharted AI usages, might be psychologically dangerous.

In this simulation you take the role of the Israeli Prime Minister, starting right before 07/10/2023, and need to make decisions. An AI model running the game engine ('dungeon master') decides the in-game reality outcome of your decisions. your actions can be choosing from several options given to you, or free text instructions.

The simulation is based on a capable AI model, a runbook 'bible' that instructs the model how to view the world and how to orchestrate the actors, and a map of initial potential flows.

The maturity level of this POC is basic - just enough to start and feel real, but not covering the full depth of reality. for example - the agent is instructed to think and reason for each actor or enemy of Israel in their own language - but AI content policy is assumed to prevent it from fully embrace certain militant roles.

See build&run instructions in subdir israel-statecraft/README.md
